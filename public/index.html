Finance API

This server provides the data for The Art of Finance React site. Click a request below to see what it returns.

Available Requests

GET /api/assets

Returns all 8 alternative asset classes. Each one has an id, name, image name, category, risk level, typical return, liquidity, and description.

View All Asset Classes
GET /images/{img_name}

Returns the picture for an asset class, using the img_name from the list above.

Example: Real Estate Picture
POST /api/assets

Adds a new asset class. Send it as form data with a picture in the img field. Every field is checked before the asset is added:

  • name and category: 3 to 40 characters
  • risk and liquidity: 3 to 20 characters
  • typical_return: 2 to 20 characters
  • description: 10 to 300 characters
  • img: a picture file (required)
Try It on the Alternatives Page
PUT /api/assets/{id}

Edits the asset class with that id. Send it as form data with the same fields and rules as POST. The picture is optional here, and the old one is kept if no new picture is sent.

Try It on the Alternatives Page
DELETE /api/assets/{id}

Removes the asset class with that id and returns the one that was removed. If no asset class has that id, the server sends back a 404 error.

Try It on the Alternatives Page
